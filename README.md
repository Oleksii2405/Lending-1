# Летюча дрифт-машинка 2 в 1 — лендинг

Односторінковий продаючий лендинг (vanilla HTML/CSS/JS + PHP-обробник форми).
Мова: українська. Валюта: гривня. Мобільний пріоритет.

## Структура проєкту

```
letyucha-mashynka-landing/
├── index.html              головна сторінка (усі 9 блоків)
├── privacy-policy.html     заглушка політики конфіденційності
├── delivery-terms.html     заглушка умов доставки та оплати
├── returns.html            умови обміну/повернення (з реальним текстом закону)
├── api/
│   └── order.php           серверний обробник форми замовлення
├── assets/
│   ├── css/style.css       усі стилі (mobile-first, брейкпоінт 768px)
│   ├── js/main.js          розрахунок ціни, маска телефону, валідація, пікселі
│   └── img/*.svg           ПЛЕЙСХОЛДЕРИ фото — замініть на реальні
```

## Що зроблено за референсом novabiz.shop/letyucha-mashyna-mhtt/

Дані перевірені безпосередньо на сайті-референсі (сторінка відкрита і прочитана
живим браузером, бо прямий автоматичний запит повертав 403). Усі ціни,
знижки за кількість та характеристики — **точно** як на оригіналі:

- Базова ціна: 949 грн (стара ціна 1380 грн, −31%)
- 2 шт = 1803 грн (−5%), 3 шт = 2562 грн (−10%), 4 шт = 3226 грн (−15%)
- Характеристики: тип 2в1, корпус — високоміцний пластик, акумулятор
  (USB-заряджання) у машинці, 3 батарейки АА **окремо** для пульта,
  дистанція керування до 40 м
- Комплектація: машинка, пульт, USB-кабель, інструкція, фірмове пакування
- Оплата — виключно при отриманні (накладений платіж), жодної передоплати

Фотографії товару з референсу **не копіювалися** (чужий контент, hotlink
до чужого сервера ненадійний і некоректний). Замість них — підписані
плейсхолдери в `assets/img/`.

## Перед запуском: що обов'язково заповнити

1. **Фото товару.** Замініть файли в `assets/img/` на реальні фото (назви та
   розміри вказані прямо на кожному плейсхолдері):
   `hero-product.svg→.jpg`, `mode-drive`, `mode-drift`, `mode-fly`,
   `lifestyle-gift`, `box-contents`, `og-image`. Якщо замінюєте на `.jpg`,
   оновіть розширення в `index.html` (пошук `assets/img/`).
2. **Домен.** У `<head>` сторінки `index.html` замініть `your-domain.ua` в
   `canonical`, `og:url`, `og:image` на реальний домен.
3. **Піксели.** У `<head>` розкоментуйте потрібні блоки (Meta Pixel, TikTok
   Pixel, GA4) і вставте свої ID замість `PIXEL_ID` / `G-XXXXXXX`.
4. **Реквізити продавця.** У футері `index.html` і в юридичних сторінках —
   секції з позначкою `[Заповніть: ...]` (назва ФОП/ТОВ, телефон, email,
   адреса). Я їх не вигадував навмисно.
5. **CRM/Telegram.** У `api/order.php` вкажіть `TELEGRAM_BOT_TOKEN` і
   `TELEGRAM_CHAT_ID`, щоб заявки одразу прилітали в Telegram. Якщо потрібна
   інша CRM — додайте свій запит у функцію `notifyCrm()`/`notifyTelegram()`.

## Як запустити локально

Потрібен PHP (для роботи форми замовлення):

```bash
php -S localhost:8090 -t letyucha-mashynka-landing
```

і відкрити `http://localhost:8090/`.

Без PHP сторінка теж відкриється (навіть подвійним кліком по `index.html`),
але форма коректно покаже помилку відправки — це навмисна поведінка:
**сторінка ніколи не показує "дякуємо за замовлення", якщо дані фактично
не дійшли до сервера.**

## Деплой на звичайний PHP-хостинг

Білд не потрібен — просто завантажте весь вміст папки
`letyucha-mashynka-landing/` (включно з `api/`) у кореневу директорію сайту
через FTP/файловий менеджер хостингу. Переконайтеся, що:

- на хостингу увімкнено PHP 7.4+;
- файл `api/orders.log` (створюється автоматично після першого замовлення)
  не доступний напряму з браузера — додайте правило заборони в
  `.htaccess` (Apache) або у конфіг nginx, якщо хостинг на nginx.

## Що перевірено

- Розрахунок суми при виборі 1/2/3/4 шт синхронізований у трьох місцях:
  блок "Бери більше — плати менше", форма замовлення, нижня sticky-кнопка.
- Маска телефону `+380 (XX) XXX-XX-XX` з валідацією рівно 9 цифр.
- Валідація імені та телефону з читабельними повідомленнями про помилки.
- Форма не показує фейковий успіх, якщо запит до `api/order.php` не вдався
  (перевірено без PHP-сервера — коректно показує помилку мережі).
- Захист від подвійної відправки (кнопка блокується на час запиту).
- Honeypot-поле проти найпростіших ботів (на фронті і на бекенді).
- Мобільна версія (375px) і десктоп (1280px) — перевірено в браузері:
  без горизонтальної прокрутки, sticky-кнопка внизу не перекриває форму.
- Lazy-loading для всіх зображень нижче першого екрана.

## Чого немає навмисно

- Фейкових відгуків, лічильників "залишилось N штук", штучних таймерів —
  як прямо просив бриф.
- Реальної інтеграції з конкретною CRM (підключається одним запитом у
  `order.php`, але який саме сервіс — вирішує власник магазину).
